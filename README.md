# WebGiaoDuc — Trang demo trò chơi

Mở nhanh trang web tĩnh cục bộ:

- Mở file `index.html` trong trình duyệt (double-click) hoặc dùng một web server tĩnh như `Live Server` trong VS Code.

File chính:

- `index.html` — giao diện và nội dung dựa trên `context.md`.
- `styles.css` — kiểu dáng và màu sắc.
- `script.js` — tương tác bật/tắt chi tiết thẻ.

Muốn tôi bổ sung: tải ảnh minh họa, thêm trang admin để quản lý đề bài, hoặc deploy lên GitHub Pages? Trả lời yêu cầu bạn muốn tiếp theo.
